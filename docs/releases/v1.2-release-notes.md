# Delivery ERP v1.2 Release Notes

Status: Development Complete / Pending Publication.

Version 1.2 closes the frontend-only, browser-persisted Delivery ERP product milestone. It is ready for QA validation and manual release handoff, but has not yet been published or deployed.

## Completed Areas

- Opportunity and Project workflows.
- Project Workspace.
- Systems Workspace.
- Tenant Workspace.
- Infrastructure Workspace.
- Infrastructure Maintenance.
- Warranty framework.
- Remarks framework.
- Shared dashboards.
- Workspace UI standard.
- Three-frame scrolling.
- Shared Business ID links.
- Shared status presentations.
- Shared validation standard.
- Metadata-backed pick lists currently implemented.
- POC allocation and reused-system lifecycle.
- Activity and Configuration History.
- Browser persistence.

## Architectural Boundary

Version 1.2 remains a frontend-only React/Vite application with browser-local persistence.

Known boundaries:

- No secure multi-user authentication.
- No server-side authorization.
- No production backend/database.
- No self-upgrade agent.
- No Update Agent.
- No deployment credentials or release publishing from the browser.

Version 2.0 is the phase that introduces the trusted backend, database persistence, internal authentication, roles, privileges, server-side authorization, secure sessions, Administration Console, Metadata Settings, Application Upgrade, Update Agent, and migration from browser-local data.
