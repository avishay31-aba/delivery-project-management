# Product Decision Log

This log captures durable product and architecture decisions supported by current repository documentation and implementation context. It is not a duplicate rule catalog. Authoritative behavior remains in `AGENTS.md`, `docs/architecture-handbook.md`, `docs/v1.2-standing-product-rules.md`, the ECM/BOM, BOS, PDS, ADRs, roadmap, and release notes.

If rationale is not recoverable from repository documentation, this log records it as not currently documented rather than guessing.

| V1.2 Final QA | Tenant Dashboard separates lifetime `Origin Project` from current `PIDs`, and displays PID-qualified `Requirement IDs` history.
